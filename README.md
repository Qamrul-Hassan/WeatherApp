# 🌦️ WeatherApp

A modern weather application built with **Next.js**, **Zustand** for state management, and **Leaflet** for interactive maps. It provides real-time weather updates with smart location suggestions and a beautiful UI.

## 🚀 Features

- 🌍 Location-based weather search with suggestions
- ⏱️ Real-time temperature, humidity, and wind data
- 🗺️ Interactive map powered by Leaflet
- 🌤️ Clean animations and stylish weather icons
- 📱 Responsive and mobile-friendly

## 🛠️ Tech Stack

- **Next.js** – React framework for SSR and fast performance
- **Zustand** – Lightweight state management
- **Leaflet** – For interactive map display
- **Styled Components** – For scoped component styling
- **OpenWeather API** – For real-time weather data
